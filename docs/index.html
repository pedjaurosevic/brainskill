Confirmatory study · completed

Can plain work instructions beat “think step by step” on a small local model?

BrainSkill tests label-blind operational protocols against ordinary chain-of-thought on a heavily quantized local LLM — without telling the model to “act like” a personality type or psychologist.

Author: Predrag Urošević 1,440 scored trials Freeze tag: brainskill-freeze-v3.1 Model: Muse-Glimmer-30B-exl3-2.00bpw

1. What we asked

Many prompts say “you are an INTJ” or “think like Kahneman.” That mostly measures stereotype recall. We asked something narrower:

If the model only sees concrete steps — state a claim, name what would refute it, use a tool when that helps, update, set confidence; or use a careful checklist — does that change accuracy, verbal calibration, tool use, and dependence on pasted documents, compared with plain “think step by step”?

Jung / Luria / Friston / Sternberg ideas stayed parked. This run is only four operational conditions, not a personality study and not a consciousness claim.

3. What we found (headline)

On this edge model, label-blind verification raised inspection-tool use without a significant rise in forbidden safety actions — but it did not improve verbal calibration or shrink dependence on frozen documents versus chain-of-thought.

H1-sec. Lower MCE for dual vs cot (exploratory) n.s. —

One-sentence takeaway for builders: on this cheap local model, a verification protocol moves the agent toward tools, but it is not a free metacognition upgrade.

5. Limits (said out loud)

  • verify / high_c prompts are longer than cot (instruction-length confound).
  • Domain 2/4 use regex graders; Domain 1 carries more construct validity.
  • Domain 3 safety is weak for all conditions (~48%) — protocol does not fix that alone.
  • Verbal confidence on a 2.00 bpw model may be poorly grounded.
  • Primary substrate only; optional Gemini/Grok direction check was not required for this close-out.
  • Null H1/H2 is a result, not a license to unpark parked paradigms inside this confirmatory family.
