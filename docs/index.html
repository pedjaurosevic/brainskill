Confirmatory study · completed

Can plain work instructions beat “think step by step” on a small local model?

BrainSkill tests label-blind operational protocols against ordinary chain-of-thought on a heavily quantized local LLM — without telling the model to “act like” a personality type or psychologist.

1. What we asked

Many prompts say “you are an INTJ” or “think like Kahneman.” That mostly measures stereotype recall. We asked something narrower:

If the model only sees concrete steps — state a claim, name what would refute it, use a tool when that helps, update, set confidence; or use a careful checklist — does that change accuracy, verbal calibration, tool use, and dependence on pasted documents, compared with plain “think step by step”?

Jung / Luria / Friston / Sternberg ideas stayed parked. This run is only four operational conditions, not a personality study and not a consciousness claim.

3. What we found (headline)

On this edge model, a structured checklist (high_c) delivered the highest overall accuracy (92.2%) and lowest safety violation rate (2.8%). A verification protocol raised inspection-tool use (+19.4%), but did not significantly improve verbal calibration error (MCE) versus chain-of-thought.

Takeaway for builders: on this local model, structured checklists (high_c) provide the strongest operational safeguard and highest task accuracy, while verification prompts reliably steer the model toward inspection tools.

5. Limits & Adversarial Audit

  • Evaluation artifact resolved: An adversarial audit revealed that initial ~78% scores were an artifact of regex bugs (greedy first-number extraction, matching discarded choice options, and penalizing safe refusals that quoted the command). Once hardened, true accuracy rose to 89.9%.
  • verify / high_c prompts are longer than cot (instruction-length confound).
  • H3 tool-use reflects direct instruction-following, as the prompt explicitly commands tool inspection.
  • Verbal confidence on a 2.00 bpw edge model is largely uncalibrated, but near-perfect on frontier models (Gemini Flash).
  • Parked paradigms (Jung / Luria / Friston / Sternberg) remain parked.
